Complex Number Calculator using C++

About the Project

The Complex Number Calculator is a C++ mini-project developed using Object-Oriented Programming concepts. It performs addition and subtraction of two complex numbers using operator overloading.

Features

- Stores real and imaginary parts of complex numbers.
- Performs addition of two complex numbers.
- Performs subtraction of two complex numbers.
- Displays results using the overloaded << operator.
- Validates user input.
- Handles positive and negative imaginary parts.

OOPS Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Operator Overloading
- Friend Function

Technologies Used

- Programming Language: C++
- Concepts: Object-Oriented Programming
- Compiler: G++ / Any C++ Compiler

How to Run

1. Download or clone this repository.
2. Open the project in a C++ compiler.
3. Compile the source code.
4. Run the program.
5. Enter the real and imaginary parts of two complex numbers.
6. View the addition and subtraction results.

Sample Output

First number: 4 + 3i

Second number: 2 + 5i

Addition: 6 + 8i

Subtraction: 2 - 2i

Conclusion

This project demonstrates the practical use of Object-Oriented Programming concepts in C++. It explains how operator overloading makes arithmetic operations on complex numbers simple and convenient.
